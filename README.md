
# QuickNotes

QuickNotes is a simple note-taking web application that allows users to create, organise, search and delete notes. Notes can be assigned to Personal, Work or Study categories. The application saves notes in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes with different categories.
- Validate empty notes and notes longer than 200 characters.
- Display the date and time each note was created.
- Delete individual notes.
- Clear all notes with confirmation.
- Search notes without case sensitivity.
- Display the total number of notes.
- Save notes using localStorage.
- Responsive design for mobile and desktop.

## How to Run Locally

1. Download or clone the repository.
2. Open the `quicknotes-app` folder.
3. Open `index.html` in your browser.
4. Start adding and organising your notes.

No additional installation is required.
